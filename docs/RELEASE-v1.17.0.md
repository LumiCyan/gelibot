# GeLi Bot v1.17.0

把 QQ 群接到 Minecraft 服务器的 Windows 桌面端。这一版 `/在线` 学会了「发图」——
服务器名、在线人数、玩家真头像一张卡片看清；顺手治好了「换版本要重新配置」的老毛病，
并修掉「漏个空格机器人装死」的坑。

---

**`GeLi Bot v1.17.0.exe`** —— 单文件绿色版，双击即用，无需安装。

## 本版核心之一：`/在线` 图片卡片

### 从「一坨终端文本」到「一张卡片」

以前 `/在线` 是把 RCON 的原始终端输出转发到群里（带颜色代码，群里还看不清）。
现在可以改成**一张图片卡片**：

- **服务器名可自定义**（不再写死「创造服」）
- **在线人数 + 占用进度**（`3 / 20`，进度条直观）
- **玩家头像网格**：已绑定 QQ 的玩家显示**其 QQ 头像**（腾讯官方头像 CDN，免鉴权，
  本地缓存 7 天）；未绑定或取图失败显示首字母色块，**头像失败不影响整张图**

### 图片怎么来的

不需要任何第三方渲染库——**程序自己的 Chromium**（它就是 Electron 应用）
开一个隐藏透明窗口，把 HTML/CSS 截成 PNG 发出去：

- 中文字体直接用系统字体，透明圆角高清输出
- 卡片文件名按**内容哈希**复用，连查 `/在线` 不会堆出一堆图片文件，旧的自动清理
- 实测真机渲染 **786ms**（含 4 个真实头像下载 385ms + 渲染 393ms）

### 插件服也能用

实测发现：装了 CMI 这类插件的服务器会把 `list` 指令接管掉，返回**空字符串**。
现在程序检测到「执行成功但内容为空」会自动改走 `minecraft:list`，成功后**记住可用命令**，
下次不再重复探测。全程只用 RCON，不需要服务端插件。

### 永不「裸奔」的降级链

图片 → 文字模板 → 原生 RCON 转发 —— 逐级回退。
渲染异常、发图失败都会自动降一级，绝不会因为卡片出问题就查不了在线。

**默认关闭**：不启用时 `/在线` 行为与旧版**逐字节一致**（有专门的回归用例守着）。

界面新增「在线展示」配置卡片：启用开关、服务器名、刷新间隔、是否显示头像、
发图开关、文字模板，以及一个**预览按钮**——用界面上的当前配置当场出图，
**未保存也能先看效果**。

## 本版核心之二：数据目录跟随程序（换版本不再重新配置）

### 问题出在哪

数据目录绑死在 `%APPDATA%\<产品名>` 上，而产品名历史上改过三次
（`GeLiCraft` → `gelibot` → `GeLi Bot`）。于是**每换一个版本就像重装**：
配置、绑定全没了，而且全程静默，连个提示都没有。

### 新规则

**程序目录（exe 旁边）如果有 `data/config.json`，就以它为准。**

把 `data` 文件夹和 exe 放在一起，之后换任何版本、换任何电脑，
拷贝这一整个文件夹就是全部数据。系统用户目录模式照常可用，
没有 `data` 文件夹时行为与旧版完全一致。

- 便携版特判：读 `PORTABLE_EXECUTABLE_DIR`（应用被解压到 `%TEMP%` 运行，
  程序自身路径是临时目录，不能用）
- exe 旁 `data` **不可写**时（放在了 Program Files 等位置）自动回退到系统用户目录
  并给出提醒，避免「保存了但没生效」的静默失败

### 配置导出 / 导入

界面新增「数据与备份」卡片：

- 显示**当前数据目录与来源**、一键打开目录
- **导出配置**：默认剔敏（两个 RCON 密码 + AccessToken），勾选才会带上
- **导入配置**：走既有配置迁移链（老版本导出的文件自动补齐新字段），
  也接受裸 `config.json`
- **把配置存到程序目录（绿色版）**：一键迁移

导入是**合并而不是覆盖**——脱敏文件不会抹掉本机已有密码；绑定关系按
「QQ + 玩家 ID」去重追加（玩家 ID 大小写不敏感）。

## 本版核心之三：未知指令不再静默

### 那个「机器人装死」的坑

群里发 `/绑定Steve`（**漏了空格**）——整串被当作指令名，匹配失败后**一声不吭**，
看起来就像机器人死了。这个问题排查了很久：因为主进程不写日志文件，
打包版双击运行时错误全部丢失，全靠手动复现。

### 修法

- 斜杠开头的消息匹配不上内置指令时，**明确回复**
  「未知指令 `/xxx` + 发送 `/帮助` 查看全部可用指令」——斜杠本来就是「我要执行指令」的声明，不该静默
- **漏空格时直接给出正确写法**：`/绑定Steve` → 提示「是要发送 `/绑定 Steve` 吗？」
- 只在「接收参数」的指令里做粘连切分，避免把 `/我的绑定` 误引导成 `/我的绑定 abc`
- 前缀匹配按名字长度倒序，保证 `/查询绑定abc` 不会被 `/查询` 抢先切掉
- 剩余部分需匹配 `^[A-Za-z0-9_\u4e00-\u9fa5-]+$`，避免对无关串误报

  降级链、界面预览

- **全量审计日志**：每条指令执行与拦截都有记录
- **6 个功能页面**的图形界面

## 快速开始

1. 双击 `GeLi Bot v1.17.0.exe`（首次启动需 3–10 秒解包）
2. 「连接设置」页 → 点 **启动 SnowLuma** → 自动打开后台 `http://127.0.0.1:5099`
3. 后台里扫码登录 QQ
4. 后台 → **节点配置 → WS 服务端**，复制 **accessToken**
5. 回到本程序，填入 `ws://127.0.0.1:3001` 和刚复制的 Token，**保存配置**
6. 顶栏「QQ」变绿即通

### 想用图片卡片

1. 「连接设置 → 在线展示」里勾选启用，填服务器名（比如「创造服」）
2. 点「预览卡片」——**不保存也能先看效果**
3. 保存后群里发 `/在线`

### 想用绿色版数据目录

1. 在 exe 旁边建一个 `data` 文件夹（或点「数据与备份 → 把配置存到程序目录」）
2. 以后换版本只把 exe 替换掉，配置跟着文件夹走

## 已知限制

- **服务端插件桥仍未实现**：玩家在游戏内打 `/easybot bind` 无法直接触发取码
  （双服务器流程已经绕开了这个需求，插件桥仅对「想在游戏内直接取码」的场景仍有价值）
- **RCON 密码明文存储**在 `config.json`，请确保该目录权限可控。
  RCON 走明文 TCP，务必只在 `127.0.0.1` 监听，不要暴露到公网
- **仅 portable 单文件版**，暂无安装版
- 卡片头像来自腾讯官方 CDN，**不需要登录凭证**；取不到时自动回退首字母色块

## 许可提示

本程序内置的 **SnowLuma** 是源码可见的**非商业**许可项目，核心 native 组件闭源。

- 自己用、团队内部用：没问题
- **把本 exe 对外分发**：因含 SnowLuma 二进制，严格来说需先取得其授权。
  若要公开发布，建议改用「不内置」方式：让对方自行下载 SnowLuma，
  再用启动器的「程序目录」指向它。

从源码构建时不需自带 SnowLuma —— 跑 `npm run fetch:snowluma` 按需拉取即可。

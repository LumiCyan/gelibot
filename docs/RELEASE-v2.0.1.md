# GeLi Bot v2.0.1

一次只做界面的更新：把「点一下，页面啪地换掉」改成**有方向的过渡**。

功能一个没加，行为一个没改。2.0.0 的配置、绑定、数据全部原样保留。

---

## 一、切页现在有方向了

以前点侧边栏，内容是新的一条，但**看不出你是往下走还是往上走**。

现在按导航里的先后顺序判断方向：

```
往下点（连接设置 → 玩家统计）   内容从下方浮起 7px
往上点（玩家统计 → 自动回复）   内容从上方落下 7px
```

这样「上一页 / 下一页」在视觉上和你脑中的位置感一致，而不是每次都像重新打开一个新窗口。

## 二、内容是一个一个出现的

不是整页一起淡入——那和按 F5 刷新没区别。每个顶层块各自浮起，按顺序错开 22ms：

```
标题        ↗ 0ms
说明        ↗ 22ms
卡片一      ↗ 66ms
卡片二      ↗ 88ms
```

长页面不会「排队排到最后才出现」：第 8 块往后统一 150ms，不再递增。

**曲线是特意前置的。** 卡片是白底、页面是浅灰底，透明度半开时卡片几乎融进背景——按常规的 ease-out 曲线，前 120ms 整页看起来像空白。把控制点拉到 `0.85` 之后，头三分之一就基本变实，剩下的时间只走位移：

| | 120ms 时的透明度 |
| --- | --- |
| 常规 ease-out | 0.79 / 0.71 |
| 现在 | 0.92 / 0.86 |

## 三、导航高亮改成滑块

以前是背景色直接跳到新项。现在是**一块高亮平滑滑过去**，从旧项一路移动到新项身上，时长 220ms。

代价是它中途会扫过中间那几项，一两帧里看到高亮从别人身上掠过。这是有意保留的——那一下正是「我跳了很远」的信息。

## 四、其余几处衔接

| 地方 | 以前 | 现在 |
| --- | --- | --- |
| 保存提示 | 突然出现、突然消失 | 下滑淡入 → 停留 → 上浮淡出，2.6s 走完 |
| 状态灯 | 「启动中」是个死黄点 | 呼吸 1.3s，能看出还在尝试；错误态保持静止 |
| 按钮 | 蓝 → 浅绿硬切 | 0.18s 渐变 |
| 输入框聚焦 | 光圈瞬间出现 | 0.15s 渐显 |
| 排查指引展开 | 内容直接顶出来 | 淡入 0.18s |

提示条的进出都在一个动画里完成，时长和 JS 里卸载它的 2600ms 对齐——所以不会出现「先消失、再被移除」的二次闪烁。

## 五、顺手修掉的两个问题

**1. 切页后滚动位置不归零**

页面滚动到一半去点别的菜单，新区块会停在上一页的滚动位置，得手动往上滚。现在切页即回顶。

**2. 首次进入时导航滑块不出现**

这个是写滑块时发现的：应用启动时配置还没到，整页只渲染一行「正在加载配置…」，侧边栏根本不在 DOM 里——那次测量自然拿不到节点。等配置到了，`page` 没变，测量就再没跑过，滑块一直不显示，直到你第一次切页。

修法是把「配置到没到」也放进测量依赖里。

## 六、无障碍

系统里开了「减少动态效果」时，全部退化：

- 进场动画时长压到 0.01ms（等于直切），错开延迟清零
- 状态灯停止呼吸
- 提示条**保留可见**——它的动画末帧就是 `opacity: 0`，如果按常规做法压到 0.01ms，会直接停在「已淡出」，等于什么都看不见

这条有单独用例守着。

## 七、验证

**824 项单元测试** + **21 项界面动效验证**。

动效这种「看不到代码就看不出对错」的东西，光靠 tsc 是验不出来的。所以加了 `npm run ui:shot`：Electron 真实加载构建产物，注入一份假 bridge 喂固定数据，然后

- 量高亮块与当前项的坐标是否逐像素对齐
- 点导航，检查每个顶层块是否都挂上动画、延迟是否真的递增
- **把动画暂停在 120ms** 截一张中间帧，确认各块透明度不同（证明是错落而非整块淡入）
- 切页后重新量滑块，确认它跟到了新项、滚动归零
- 用 CDP 模拟 `prefers-reduced-motion: reduce`，确认降级生效且提示条仍可见

21 项全通过。产物在 `.stage/ui/*.png`。

# GeLi Bot v1.15.0

把 QQ 群接到 Minecraft 服务器的 Windows 桌面端。这一版**内置了 SnowLuma**，不用再单独下载配置机器人框架；同时改了名、换了配色，并修掉了一个会让 QQ 死活连不上的坑。

---

## 下载

**`GeLi Bot v1.15.0.exe`** —— 单文件绿色版，双击即用，无需安装。

- 大小约 **93 MB**（其中约 60 MB 压缩后来自内置的 SnowLuma 完整版）
- 支持 Windows 10 / 11 x64
- 不写注册表、不留后台服务，删掉 exe 即卸载

## 本版新增

### 内置 SnowLuma + 一键启动器

「连接设置」页最上方新增 **SnowLuma 启动器**，不用再手工解压、跑 `launcher.bat`、开浏览器：

- **一键启停**：直接管理 SnowLuma 进程，显示 PID 与状态
- **自动开后台**：检测到 WebUI 真正监听后自动打开浏览器
- **凭据直取**：从启动日志抓出首次生成的 `admin / 密码`，一键复制
- **程序目录可换**：留空用内置版，也可指向你自己的 SnowLuma
- **数据分离**：SnowLuma 的 `config/`、`logs/` 写在数据目录，程序目录保持只读
- **随程序退出**：默认关闭本程序时一并停止，可取消勾选让它继续后台跑
- **重复启动保护**：启动前探测端口，已有实例时给出明确提示

### 改名与配色

产品名从 GeLiCraft 改为 **GeLi Bot**；配色改为**白底 + 蓝主色 + 浅绿点缀**，重新绘制了应用图标。

### 修复：QQ 连接状态与错误提示

- **连接错误现在能直接照做**。以前连不上时只显示 `Unexpected server response: 401`，完全看不出该干什么；现在会明确告诉你去哪填 Token：

  > 认证被拒（HTTP 401）：服务端要求 Token，但这里留空了。请到 SnowLuma 后台 → 节点配置 → WS 服务端，复制 accessToken 填到「访问令牌」

  同时覆盖了端口填错（426/404）、端口没监听、域名解析失败、超时等情况。

- 顶栏状态徽标支持**悬停查看完整错误原因**，连接页也用醒目横幅替代了原来的灰色小字。

- 「连不上？按这三步排查」折叠指引：Token 一致性 → 端口别填成 WebUI 的 → WS 服务端是否启用。

### 配置迁移

从旧版 GeLiCraft 升级时，首次启动会自动把 `%APPDATA%\GeLiCraft\data\` 的配置复制过来（复制而非搬移，旧目录保留），不用重填 RCON 密码和绑定关系。

## 快速开始

1. 双击 `GeLi Bot v1.15.0.exe`（首次启动需 3–10 秒解包）
2. 「连接设置」页 → 点 **启动 SnowLuma** → 自动打开后台 `http://127.0.0.1:5099`
3. 后台里扫码登录 QQ
4. 后台 → **节点配置 → WS 服务端**，复制 **accessToken**
5. 回到本程序，填入 `ws://127.0.0.1:3001` 和刚复制的 Token，**保存配置**
6. 顶栏「QQ」变绿即通

> **最容易踩的坑**：Token 必须与服务端完全一致。服务端设了 Token 而这边留空，握手会直接 401。
> 界面上的固定提示与错误横幅都会提醒这一点。

详细步骤见随包附带的 `使用说明.md`。

## 这一版包含的功能

- **账号绑定双模式**：双向验证（游戏内取码 + 群内提交）／社交平台信任（群里直接绑）
- **验证码**：位数、字符集（易混淆字符已剔除）、有效期可配，一次性语义，重取作废旧码
- **强制绑定**：未绑定进服踢出（RCON kick）
- **退群自动解绑**、**绑定后改群名片**（三种策略）
- **可自定义消息模板**（6 个文案，支持 `#code` `#time` `#account` `#player` `#why` 占位符）
- **权限路由**：群 / 私聊 / 管理员三类白名单，9 条内置指令
- **安全**：指令走模板 + 参数白名单校验（`^[A-Za-z0-9_]{3,16}$`），杜绝拼接注入；同用户限流
- **全量审计日志**：每条指令执行与拦截都有记录
- **6 个功能页面**的图形界面

## 已知限制

- **服务端插件桥尚未实现**：玩家在游戏内打 `/easybot bind` 目前无法触发取码。
  验证码的签发、RCON 播报、校验链路都已完整，缺的只是「服务端 → 本程序」这一段触发。
  现阶段可用两种替代：① 在绑定页用「签发验证码」代发；② 改用社交平台信任模式。

- **RCON 密码明文存储**在 `config.json`，请确保该目录权限可控。
  RCON 走明文 TCP，务必只在 `127.0.0.1` 监听，不要暴露到公网。

- **仅 portable 单文件版**，暂无安装版（无开始菜单快捷方式与卸载项）。

## 许可提示

本程序内置的 **SnowLuma** 是源码可见的**非商业**许可项目，核心 native 组件闭源。

- 自己用、团队内部用：没问题
- **把本 exe 对外分发**：因含 SnowLuma 二进制，严格来说需先取得其授权。
  若要公开发布，建议改用「不内置」方式：让对方自行下载 SnowLuma，
  再用启动器的「程序目录」指向它。

从源码构建时不需自带 SnowLuma —— 跑 `npm run fetch:snowluma` 按需拉取即可。

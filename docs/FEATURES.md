## 一、架构前提

| 能力 | EasyBot（MCDR 插件） | GeLi Bot（RCON 桥） |
| --- | --- | --- |
| 执行服务器指令 | RCON | ✅ RCON |
| 读游戏内聊天 | MCDR 事件钩子 | ✅ 日志监听（v1.18 已补） |
| 进服/退服/死亡事件 | MCDR 事件钩子 | ✅ 日志监听 |
| 拦截玩家进服 | MCDR 可取消事件 | 🟡 仅「进服后 kick」 |

**v1.18 补齐了最大的短板**：日志监听让本项目第一次拥有了「游戏内事件源」。
下面 200 项功能里，凡是涉及玩家行为感知的，都建立在这块地基上。

## 三、新的信息架构（12 域 · 16 个页面）

导航按**使用路径**排列，图片渲染独立成域：

```
① 接入          连接设置
② 身份与权限     账号绑定
③ 消息          消息互通 · 自动回复
④ 图片与视觉     图片渲染（独立）· 卡片模板
⑤ 指令          指令管理 · 群/私聊白名单 · 指令控制台
⑥ 数据          玩家统计
⑦ AI            AI 助手
⑧ 自动化         定时任务 · 慰问服主
⑨ 社区互动       签到与积分
⑩ 安全          审计日志
⑪ 系统          软件更新
```

> 「图片渲染」从「消息」域里拿出来单开：它现在不只是「回复要不要出图」，
> 而是一整套视觉能力（主题、字号、水印、模板、头像、报表图）。

## 四、已落地清单（v1.18）

| 模块 | 文件 | 能力 |
| --- | --- | --- |
| 日志监听 | `logwatcher.ts` | 六类事件、四格式兼容、假人过滤、轮转自适应 |
| 群服同步 | `chatbridge.ts` | 双向、CQ 降级、屏蔽、替换、静默时段、合并窗口 |
| 自动回复 | `responder.ts` | 关键词/完全/正则、冷却、仅管理员、测试 |
| 权限组 | `permissions.ts` | 四类主体、deny 优先、通配、嵌套不动点展开 |
| 统计 | `stats.ts` | 实时会话计时、容量淘汰、四维排行 |
| 定时任务 | `task.ts` | 间隔 + 每日定点、执行历史 |
| AI | `ai.ts` + `ai-util.ts` | OpenAI 兼容五家预设、上下文、配额、输出清洗 |
| 图片回复 | `card-generic.ts` + `image-reply*.ts` | 任意文本→卡片、自动排版、串行渲染、失败回退 |
| 慰问服主 | `owner-care.ts` | 每日播报第 N 天、`/慰问`、一键重置 |
| 差量更新 | `updater.ts` + `bsdiff.mjs` | bsdiff 补丁、sha256 二次校验、镜像回退 |
| 安装程序 | `electron-builder.config.js` | NSIS 中文向导 + portable 双形态 |

测试：**810 项**（含 12 套专项用例）。

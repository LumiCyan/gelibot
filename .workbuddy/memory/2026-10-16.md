## 追加 2：排查「发绑定指令机器人不回复」—— 定位到 3 条静默丢弃通道

用户现象：在**另一台电脑**上发 `绑定"xx"`，QQ 里机器人完全没反应。

**根因（按可能性排序）：**

1. **指令必须带 `/` 前缀**（`src/main/router.ts:171`）
   `if (!raw.startsWith('/')) return { handled: false }` —— 静默丢弃，不回复。
   用户发的是 `绑定xx`（无斜杠）→ 永远不会有反应。正确：`/绑定 Steve`。

2. **有 `/` 但「绑定」与参数之间必须有空格**（`router.ts:181-184` 按空白切分）
   `/绑定xx` → name=`绑定xx`、args=[]；`matchBuiltin` 是**全等匹配** → 未命中 →
   落到 `handleRconCommand` → `findRule` 也找不到 → `{handled:false}` **静默**。

3. **白名单为空 = 全部拦截**（`router.ts:96-109` `isSourceAllowed`）
   群聊：`groupEnabled` 为 true 时还要 `groups.includes(群号)` 或发送者在 `admins` 里；
   私聊：`privates.includes(QQ)` 或 `admins`。
   新电脑上三者都是空数组 → **任何消息都在第一步被丢掉**。
   UI 原文：「只有白名单内的会话才会被处理；管理员不受白名单限制。」

**会回复但容易误导的两条（不是静默）：**

4. `verifyServer.enabled` 默认 **false**（`defaults.ts:83`）→ 新装机上新流程是关的。
   此时 `/绑定 Steve` 返回 `[绑定失败] 验证码无效或已过期，请重新获取`，
   看起来像流程坏了，其实是要去「连接设置 → 验证服（双服务器绑定流程）」勾上并填 RCON。
5. 玩家 ID 规则 `PLAYER_ID_RE = /^[A-Za-z0-9_]{3,16}$/`（`binding.ts:9`）——
   **3~16 位**。2 位的测试名（如 `xx`）会走 `bindUsage()` 回用法提示。

**快速判别法**：让对方发 `/帮助`（带斜杠）。
- 有回复 → 通路正常（SnowLuma + 白名单都 OK），纯粹是指令格式写错；
- 没回复 → 是白名单没放行，或 SnowLuma 没连上（看顶部 QQ 状态灯）。

**待办候选**：给「像指令但缺 `/`」的消息加一句轻提示，避免用户对着静默的机器人发懵。

## 追加 3：真实根因确认 + 修复（「加了 ID 就没反应」）

用户补充线索：`/绑定` 会回用法提示，**加了 ID 之后没有任何反应**。
这条线索把范围压到 `handleBuiltin` 的 bind 分支之后，因为前四道关口都一样。

**复现后确认：真正的根因是「指令名和参数之间漏了空格」。**

| 输入 | 修复前 | 修复后 |
| --- | --- | --- |
| `/绑定` | 回复用法 | 回复用法 |
| `/绑定 Steve` | 回复发码 | 回复发码 |
| **`/绑定Steve`** | **静默** | **提示「需要一个空格，试试 /绑定 Steve」** |
| `/绑定xx` | 静默 | 提示 |
| `/在线xx` | 静默 | 提示「未知指令，发送 /帮助」 |
| `/帮组`（错别字） | 静默 | 提示「未知指令，发送 /帮助」 |

机制：`handle()` 按**空白**切分得到 `name` 与 `args`（`router.ts:181-184`），
`matchBuiltin` 是**全等匹配**；`/绑定Steve` 整串成了指令名，内置和自定义指令都匹配不上，
`handleRconCommand` 返回 `{handled:false}` → 静默丢弃。

**修复**（`src/main/router.ts`）：
- `handle()` 末尾：`handleRconCommand` 没认领时不再返回静默，改为回 `unknownCommandTip(name)`。
  斜杠已经明确表示「这是指令」，静默是设计缺陷。
- 新增 `splitKnownCommandPrefix()`：把粘连的串切开，例如 `/绑定Steve` → `{绑定, Steve}`。
- 新增常量 `ARG_TAKING_BUILTINS = ['bind','unbind','queryBind']` —— **只在这些「吃参数」的
  内置指令里找前缀**。否则 `/我的绑定abc` 会被误提示成 `/我的绑定 abc`（该指令不吃参数）。
  自定义指令则按 `enabled && allowArgs` 纳入。长名优先排序，保证 `/查询绑定abc` 不会被 `/查询` 抢先切。
- 剩余部分要求匹配 `^[A-Za-z0-9_\u4e00-\u9fa5-]+$`，避免对无关串误报。

**测试**：`test-router.cjs` 新增「未知指令」章节 13 项，总数 **317 → 330**，全部通过。
typecheck 干净。

**重要发现（未修）**：主进程**完全不写日志文件**，`main.ts` 的
`catch (err) { console.error('[router] 处理消息出错:', err) }` 在打包版双击启动时
输出会丢失 —— 这类「静默 bug」因此极难排查。建议后续加日志落盘或把错误暴露到 UI。

### 图片渲染可行性验证（已跑通，spike 在 `.stage/card-spike/`）

用户追问「渲染为图片不行吗」→ 做了真实验证，结论：**完全可以，且零新依赖**。

**发送端（SnowLuma 源码实证）**：`snowluma/index.mjs` 里有
`isInlineMediaSource` → `/^(base64:\/\/|data:)/i`；图片源支持 `file://` 本地路径 /
`http(s)://` / `base64://`；内部生成 `[CQ:image,file=...,url=...]`。
→ 走现有 `sendGroupMessage(groupId, '[CQ:image,file=base64://...]')` 即可发图。

**渲染端（spike 实证）**：隐藏 BrowserWindow（`show:false, transparent:true`）+
`loadFile` + `capturePage()` → `toPNG()`。首跑即成功（mode=hidden，不需要显示窗口）。
- 输出 750×500（系统 125% DPI，自带高清放大）、33 KB PNG、单次约 1.2s（含 Electron 冷启动）
- 圆角像素 A=0（完全透明），卡片 #17191d，中文/胶囊/进度条渲染完美
- 关键结论：**不用引 @napi-rs/canvas / satori / resvg 任何第三方渲染库**，
  不吃 asar/原生模块的坑，字体用系统字体（msyh）即可，打包体积零增加

**平台限制（必须记住）**：QQ **群名片只能纯文本**，任何机器人都一样。
图片的落点只能是：群消息（`/在线` 回复、定时/进出播报）、应用界面预览、
可选群公告（需机器人是管理员）。

**实施计划（待用户确认后开工）**：新增 `src/main/card.ts`（单例隐藏窗口渲染器 +
HTML 模板）+ `src/main/presence.ts`（数据层，RCON list 采集）；`/在线` 回复改图片、
失败自动降级为文字；头像可选（mc-heads/crafatar + 本地缓存 + 首字母兜底）。
